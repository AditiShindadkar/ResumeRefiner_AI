How it works
  1. Extract text from PDF (pdfplumber) or DOCX (mammoth) in a Python serverless function.
  2. Match skills with boundary-aware regex and an alias table, so JavaScript doesn't count as Java.
  3. Check quality with transparent rules: sections, contact info, action verbs, quantified bullets, weak phrases.
  4. Chunk and embed both documents in your browser with all-MiniLM-L6-v2 (transformers.js). The JD coverage score is the mean, over JD requirements, of each requirement's best-matching resume chunk.
  5. Optionally ask an LLM on Groq for concrete bullet rewrites.

Privacy: resume text is sent to this site's serverless functions for the rule-based checks and is not stored. It is sent to Groq only when you tick the LLM option. Embeddings are computed locally in your browser.

Limitations: the skill list is curated, so unlisted skills are invisible. Quality checks are heuristics. Cosine scores aren't calibrated probabilities, so use them to rank, not to threshold.
